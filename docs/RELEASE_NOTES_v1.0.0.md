# NeuroFlow v1.0.0

First stable release of NeuroFlow, a multi-modal RAG platform with automated evaluation and a fine-tuning pipeline.

## Highlights
- Hybrid retrieval (dense + sparse + metadata) with RRF fusion and cross-encoder reranking
- Streaming answers over SSE with citations
- Automated evaluation for every query run
- MLflow-tracked fine-tuning pipeline
- OpenTelemetry tracing (Jaeger), Prometheus metrics, structured logs
- Python SDK, enriched OpenAPI docs, and an operations runbook

See README.md for quick start and docs/retrospective.md for the project retrospective.
